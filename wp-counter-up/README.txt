WP Counter Up is a lightweight, responsive, and high-performance WordPress plugin that animates numbers from zero to a target value as they scroll into view — perfect for showcasing milestones, statistics, achievements, sales, clients, and business growth.

== Description ==

Turn your numbers into a visual story with beautifully animated counters designed to capture attention and improve engagement.

Whether you're a freelancer highlighting completed projects, a digital agency showcasing client success, an eCommerce store displaying products sold, or a business presenting company milestones, WP Counter Up helps transform static numbers into dynamic visual experiences.

Built with performance and flexibility in mind, the plugin delivers smooth scroll-triggered animations while remaining lightweight, responsive, and easy to customize — no coding required.

== Getting Started ==

1. Install and activate the plugin
2. Go to Counter Up → Add New
3. Create your counter items
4. Open the Shortcode Generator
5. Generate and copy your shortcode
6. Paste the shortcode anywhere on your site

---

== Installation ==

= Via WordPress Dashboard =

1. Go to Plugins → Add New
2. Search for "WP Counter Up"
3. Click Install Now
4. Activate the plugin

= Manual Upload =

1. Download `wp-counter-up.zip`
2. Navigate to Plugins → Add New → Upload Plugin
3. Upload the ZIP file
4. Click Install Now
5. Activate the plugin

== Frequently Asked Questions ==

= How do I add counters to my website? =

Create your counter items from the WordPress dashboard, generate a shortcode using the Shortcode Generator, and paste the shortcode into any page, post, widget, or page builder section.

= Can I display multiple counter groups on one page? =

Yes. You can create unlimited shortcode groups and place multiple counter sections anywhere on your site.

= Does the plugin work with Elementor or Divi? =

Yes. WP Counter Up works perfectly with Elementor, Divi, Gutenberg, WPBakery, and most modern WordPress page builders.

= Can I customize layouts and colors? =

Absolutely. You can customize layouts, colors, typography, spacing, animations, backgrounds, overlays, and responsive column settings.

= Is the plugin mobile responsive? =

Yes. All counter layouts are fully responsive and optimized for desktops, tablets, and smartphones.

= What number formats are supported? =

The plugin supports integers, decimals, commas, currency symbols, percentages, and mixed numeric content.

= Is the Pro version a separate plugin? =

Yes. The Pro version is an add-on plugin that extends the functionality of the free version.
