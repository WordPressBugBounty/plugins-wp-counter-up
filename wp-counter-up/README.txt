WP Counter Up is a lightweight and responsive WordPress plugin that animates numbers from zero to a target value when they become visible on the screen. Perfectly designed to showcase clients, sales, achievements, and milestones.

== Description ==

Display beautifully animated counters to showcase your stats, achievements, and milestones. Smooth, responsive, and lightweight—add them anywhere using simple shortcodes or widgets.

== Installation ==

= Via WordPress Dashboard =
1. Go to your WordPress admin panel
2. Navigate to Plugins → Add New
3. Search for "WP Counter Up"
4. Click **Install Now** and **Activate**

= Manual Upload =
1. Download `wp-counter-up.zip`
2. Go to Plugins → Add New → Upload Plugin
3. Upload the ZIP file and click **Install Now**
4. Activate the plugin
